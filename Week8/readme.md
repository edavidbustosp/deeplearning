CNN y Transfer Learning

para este ejercicio se usaron una CNN base y un modelo de transfer learning

CNN desde cero
MobilenetV2 (Preentrenado)

El modelo de transfer learning tuvo un mejor desempeño al inicio y mejor velocidad

Lo que sucede en este ejercicio es que el CNN desde cero aprende al momento en que se ejecuta, bordes, formas, texturas. Este modelo tarda mucho más tiempo enejecución mientras se efectúa el aprendizaje.
 lo que sucede con transfer learning es que ya viene aprendido, por lo tanto utiliza dicho conocimiento.

Extracción de características de una matriz mediante el uso de un filtro o kernel
En este ejercicio se muestra la implementación de convolución de matrices en imágenes con la 
aplicación de Padding y Stride

- Se realiza un primer ejercicio sin padding para tener una comparación base antes de asignar un padding.
- Esta sería una salida pequeña
- Posterior se procede a asignar un padding en donde la imagen mantiene un tamaño similar.
- Al asignar un stride mayor la salida será más pequeña.

* La convolución permite la identificación de patrones en una imagen aplicando un kernel el cual recorre la matriz
* El padding conserva la dimensión espacial de la imágen con el objetivo de evitar perder información en los bordes
* El stride maneja el tamaño de mapa de características de modo que si se aumenta disminuye la resolución lo cual mejora la eficiencia.

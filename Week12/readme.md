Implementación de modelos de Deep Learning para análisis de series temporales

En este ejercicio se utilizó:
- Redes recurrentes LSTM
- Mecanismos de Atención
- Una aproximación básica de transformer

Lo que se pretende con este ejercicio es comprender cómo los mecanismos de atención
permiten que un modelo identifique las partes de una secuencia que tienen más 
importancia para realizar una predicción

Concepto.

Una serie Temporal es un conjunto de datos organizados en el tiempo como por ejemplo:
- Temperatura diaria
- Tráfico en una red
- Ventas mensuales

Para poder administrar las epocas ao número de veces que se recorren los datos
Se declaró una variable epocas de modo que par las pruebas se pueden ajustar
las pruebas según se necesite.

En este ejercicio se utiliza MSE que mide que tan equivocada están las predicciones

Con los mecanismos de atención se han generado modelos como:
- ChatGPT
- Traductores
- Modelos de reconicimiento de voz
- Visión computacional entre otras
